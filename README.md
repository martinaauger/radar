# Etiqueta Vía Cargo

Etiqueta simple para imprimir y pegar en un paquete que viaja por Vía Cargo, con pago en destino y retiro en la sucursal de Villa Urquiza.

**Para:** Pablo Villaamil · Av. Congreso 5299, sucursal Villa Urquiza · C1431AAH · 11 3763-1388

**De:** Yohana Gonzalez · 54 9 3516 08-5725

## Cómo usarla

```bash
npm install
npm run dev
```

Abrí la app e imprimí la hoja. Pegala del lado visible del paquete. La guía oficial la entrega la sucursal de Vía Cargo al imponer el envío.
